# P0 review log

## Codex adversarial review 1 (design), 2026-11-08: needs-attention

| # | Severity | Finding | Disposition |
| --- | --- | --- | --- |
| 1 | high | Grants keyed only by device id; switching server origin hands devices to the new origin | Fixed: grants keyed by (origin, device id), checked on every op; server change disconnects and rejects pending ops |
| 2 | high | Assumed iOS drops connections in the background; suspended apps get queued events and upstream reconnects only on `gattserverdisconnected` | Fixed: bridge cancels connections on `didEnterBackground`, bumps epochs, dispatches `gattserverdisconnected` on return; tests for both cases |
| 3 | medium | Aborting one watch stops the shared scan, starving other remembered devices | Fixed: `ScanCoordinator` with independent subscriptions |
| 4 | medium | Server-pushed client can outrun the installed bridge; unsupported calls can degrade silently | Fixed: `BRIDGE_VERSION`, deploy rule, native banner on any unbridged call |
